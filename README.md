# Lrマスク

Photoshop上で写真の一部を選び、標準のグループ・レイヤーマスク・調整レイヤーで部分補正するUXPパネルです。作成したPSDは、パネルを外してもPhotoshopで編集できます。外部通信は行いません。

## できること

- 写真プレビュー上をドラッグして、円形・線形グラデの形を決める
- ブラシ、選択範囲、輝度範囲、彩度範囲、全体からマスクを作る
- 「形を足す」「形を引く」「形で絞り込む（共通部分だけ残す）」で複数の形を組み立てる
- 「マスクを作成」で確定した後も、一覧から部品を選んで形・順序・演算を直す
- 「部品を削除」「削除」「マスクに追加」「マスクから削除」「マスクを絞り込む」「ブラシで加減」「範囲を反転」で範囲を編集する
- スライダーでライト、カラー、効果、カラーミキサーを補正する

## インストール

1. `node tools/build-ccx.js plugin-maskgroup` を実行して `dist-ccx` フォルダに `.ccx` を作成し、生成された `.ccx` をダブルクリックして Creative Cloud 経由でインストールします。
2. 開発者向け: UXP Developer Tools で `plugin-maskgroup/manifest.json` を追加して読み込みます。
3. Releases に `.ccx` が置かれている場合は、それをダウンロードして使えます。

## ビルドとテスト

外部ライブラリなしで実行できます。

```text
node tools/build-ccx.js plugin-maskgroup
npm test
```

詳細な操作は[docs/Lrマスクの使い方.md](docs/Lrマスクの使い方.md)を参照してください。

## 既知の制約

- スライダーを動かすと、変更の履歴が複数積まれることがあります。
- Photoshop上でマスクへ直接描き足した後にパネルで部品を動かすと、描き足しが消えることがあります。
